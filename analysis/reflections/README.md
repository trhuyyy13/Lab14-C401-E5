# Individual Reflections

Thư mục này chứa báo cáo cá nhân theo format:

- `reflection_[Tên_SV].md`

Hiện đã tạo sẵn 6 file mẫu để nhóm điền nhanh. Trước khi nộp, hãy:

1. Đổi tên file đúng tên thành viên.
2. Điền đầy đủ nội dung kỹ thuật thực tế mà từng bạn đã làm.
3. Giữ lại các phần "Bài học" và "Kế hoạch cải tiến" để thể hiện chiều sâu phân tích.
